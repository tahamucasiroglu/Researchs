Görüntü netleştirme: model seçimi

Model → ne yapar → lisans → donanım → nereden indirilir. CLI bayrakları, süreç olarak çağırma, bulut API örneği ve karar tablosu.

Doğrulama: 12 Ekim 2026 · Ölçüm: 6 GB VRAM'li dizüstü NVIDIA kartı · Ölçülmeyen değerler TAHMİN etiketli

§ 1Bir bakışta

Netleştirme (upscaling, super-resolution) düşük çözünürlüklü görseli 2×–4× büyütüp ayrıntıyı yeniden kurar. Bicubic / Lanczos yalnız ara piksel hesaplar; SR modelleri eğitimde gördüğü dokuyu uydurur. Bu yüzden sonuç keskin ama aslından farklı olabilir: yazı harfleri, yüz hatları, ince desenler değişebilir.

SSIM'e tek başına bakma

GAN modelleri ayrıntı uydurup gürültüyü sildiği için aslından uzaklaşır; SSIM çoğu zaman bicubic'in altında kalır ama göz keskin sonucu tercih eder. Kararı yan yana yakın kırpımla ver. Küçük görselde süreyi model değil süreç açılışı (Python + torch yükleme ~5 sn) belirler.

§ 7C# ile süreç olarak çağırma

Yolları ArgumentList ile ver (boşluk, !, Türkçe harf içeren yollar bozulmaz). İlerleme stderr'deki 12,34% satırlarından okunur — ondalık ayırıcı bölge ayarına göre virgül ya da nokta. Başarıyı çıkış kodundan değil çıktı dosyasından anla.

using System.Diagnostics;
using System.Globalization;
using System.Text.RegularExpressions;

static async Task<bool> NetlestirAsync(string exe, string girdi, string cikti, string model,
    int olcek, int gpu, IProgress<double>? ilerleme, CancellationToken ct)
{
    var psi = new ProcessStartInfo(exe)
    {
        RedirectStandardError = true, RedirectStandardOutput = true,
        UseShellExecute = false, CreateNoWindow = true,
        WorkingDirectory = Path.GetDirectoryName(exe)!,   // models/ klasörü exe'nin yanında
    };
    foreach (var a in new[] { "-i", girdi, "-o", cikti, "-n", model,
                              "-s", olcek.ToString(), "-g", gpu.ToString(), "-t", "0" })
        psi.ArgumentList.Add(a);

    using var p = Process.Start(psi)!;
    var yuzde = new Regex(@"^(\d+[.,]\d+)%");
    p.ErrorDataReceived += (_, e) =>
    {
        var m = yuzde.Match(e.Data ?? "");
        if (m.Success && double.TryParse(m.Groups[1].Value.Replace(',', '.'),
                NumberStyles.Float, CultureInfo.InvariantCulture, out var v))
            ilerleme?.Report(v / 100.0);
    };
    p.BeginErrorReadLine();
    p.BeginOutputReadLine();
    try { await p.WaitForExitAsync(ct); }
    catch (OperationCanceledException) { p.Kill(entireProcessTree: true); throw; }

    // girdi okunamasa da çıkış kodu 0 olabilir → çıktı dosyasına bak
    return File.Exists(cikti) && new FileInfo(cikti).Length > 0;
}

§ 8PyTorch yolu: spandrel + facexlib

  • pip install spandrel (MIT). Mimariyi dosyadan bulur; ModelLoader().load_from_file(yol) → ImageModelDescriptor (ölçek bilgisi .scale).
  • NC mimariler (CodeFormer vb.) ayrı paket: spandrel_extra_arches → install().
  • Büyük görselde karo karo işle (ör. 512 px + 32 px örtüşme); half() (fp16) VRAM'i ~yarıya indirir. RealPLKSR / DAT bazı sürümlerde fp16 desteklemez → fp32.
  • Yüz: facexlib.utils.face_restoration_helper.FaceRestoreHelper (bul, hizala 512×512, düzelt, geri yapıştır). model_rootpath verilmezse ağırlıkları kendisi indirmeye kalkar — çevrim dışı çalışacaksa dosyayı önceden koy.
  • KAÇIN pip install gfpgan / basicsr: torchvision 0.17'de kaldırılan functional_tensor'ı içe aktarır; güncel torch'la açılışta çöker.
  • Paket kurarken torch sürümünü bozmamak için --no-deps ile kurup eksik bağımlılığı (ör. filterpy) elle ekle.
  • Windows'ta cv2.imread Türkçe harfli / boşluklu yolda boş döner → np.fromfile + cv2.imdecode, yazarken imencode + tofile.

Gizlilik ve ücret

Görsel sağlayıcının sunucusuna gider; kişi yüzü / ekran görüntüsü içeriyorsa bunu kullanıcıya söyle. MP başına fiyatlandırmada çıktı boyutu (girdi × ölçek²) hesaplanır: 1080p ×4 = 33 MP. Alan adları ve fiyatlar sık değişir — gerçek isteği atmadan önce model sayfasındaki şemaya bak.

§ 10Tuzaklar (ölçülmüş)

  1. 4× modelle -s 2 resmin yalnız sol üst çeyreğini büyütür; boyut doğru, hata yok, çıkış 0. Doğal ölçekte çalıştırıp sonucu küçült (ör. Lanczos / Mitchell).
  2. -g auto çift kartlı dizüstünde tümleşik (Intel) kartı seçebilir: 3–4× yavaş. Vulkan sırası CUDA sırasıyla aynı olmak zorunda değil; -v listesinden ayrık kartı bul.
  3. -m yolunda "models" yoksa exe unknown model dir type deyip çıkar.
  4. Çıkış kodu 0 olsa da girdi okunamamış olabilir (decode image … failed) → çıktı dosyasını denetle.
  5. Topluluğun ncnn dışa aktarımları 2022 exe'sinde her zaman çalışmaz (bazıları segfault). Çökenin .pth'si spandrel'de çalışır.
  6. Bellek yetmezse karo küçültülerek (otomatik → 256 → 128 → 64) yeniden denenebilir.
  7. VRAM taşınca Windows paylaşımlı belleğe düşer: hata yok ama 5–20× yavaşlar.
  8. Çıktı büyük: 1080p ×4 PNG 40–60 MB, bellekte ~130 MB. Önizlemeyi küçültülmüş kopyadan yap; >16 MP için uyar.
