Programlama · Veritabanı ve SQL

SQL ve ilişkisel veritabanları

SQL dili ve ilişkisel veritabanlarına dair rehberler ve denemeler. Bir programlama dili bölümü değil, alandır: SQL, hangi programlama dilinden kullanılırsa kullanılsın aynı dildir; farklar dilden değil veritabanı motorundan (lehçeden) gelir. Örnekler standart SQL'dir; SQLite, PostgreSQL, SQL Server (T-SQL) ve MySQL farkları ayrıca belirtilir.

Konular çalışıldıkça eklenir · Sürüm ve lehçe davranışları değişebilir; kullandığın motorun resmî belgesinden doğrula

§ 1Konular

01

SQL Mülakat Rehberi

Mülakat ve online kodlama sınavları için kısa, anahtar kelimeli SQL: JOIN'lerde kaç satır gelir, NULL mantığı, gruplama, window fonksiyonları, klasik sorular, sınav motorunu belirleme, SQLite notları ve lehçe farkları.

Ekim 202615 bölüm+ arastirma.md

ORM tarafı dil bölümünde kalır

Bir programlama dilinden veritabanına erişim (ORM, sürücü, migration) o dilin bölümünde anlatılır: C# için EF Core ve Dapper C# / .NET · 03 Veri Erişimi, Java için JDBC ve JPA/Hibernate Java · 03 Veri ve Mesajlaşma, Python için SQLAlchemy Python · Web çatıları bölümünde. Bu alan, hangi dilden gelirsen gel aynı kalan SQL'i ve motorlar arasındaki farkları toplar.
