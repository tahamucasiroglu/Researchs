# Java

C# ve .NET bilen birinin Java dünyasına geçişi için hazırlanmış anahtar liste. Java ile C# aynı aileden gelir: sınıf, arayüz, generic, koleksiyon, bağımlılık enjeksiyonu, ORM gibi kavramların hepsinin Java'da bir karşılığı vardır. Bu bölüm bu eşleştirmeyi verir, asıl ağırlığı ise farklara (checked exception, type erasure, Maven/Gradle, Spring'in çalışma biçimi) ayırır. Türkiye'de Java ilanları .NET ilanlarından belirgin biçimde fazladır.

## İçindekiler

- [Java Dili](01-java-dili/) — JDK/JVM, sözdizimi, OOP, generics, koleksiyonlar, Stream API, exception modeli, virtual thread'ler ve sürüm sürüm modern Java. Sonunda C# → Java çeviri sözlüğü var.
- [Spring Boot](02-spring-boot/) — IoC container, bean'ler, auto-configuration, REST denetleyicileri, Spring Security, AOP, test ve Spring Cloud. Her başlıkta ASP.NET Core karşılığı verilir.
- [Veri ve Mesajlaşma](03-veri-ve-mesajlasma/) — JDBC, JPA/Hibernate, Spring Data JPA, migration (Flyway/Liquibase), NoSQL ve önbellek, Kafka/RabbitMQ ile mesajlaşma. EF Core ve MassTransit ile eşleştirmeli.
- [Ekosistem ve Araçlar](04-ekosistem-ve-araclar/) — Maven, Gradle, JUnit 5, Mockito, MapStruct, Lombok, loglama, statik analiz, profil çıkarma, paketleme ve CI/CD. "AutoMapper'ın karşılığı ne?" türünden soruların cevabı burada.
