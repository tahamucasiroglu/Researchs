# Ekosistem ve Araçlar

Java projeleri Maven veya Gradle ile derlenir; ikisi de bağımlılıkları Maven Central'dan çeker (NuGet'in karşılığı). Test için JUnit 5 ve Mockito (Moq'un karşılığı), nesne eşleme için MapStruct (AutoMapper'ın karşılığı; yansıma yerine derleme zamanında kod üretir), kalıp kodu azaltmak için Lombok kullanılır. Loglamada SLF4J arayüzü ile Logback veya Log4j2 uygulamaları standarttır.

Sayfa ekosistemi kategori kategori verir: hangi iş için hangi araç kullanılır, .NET'teki karşılığı nedir, nelere dikkat etmek gerekir.
