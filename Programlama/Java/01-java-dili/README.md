# Java Dili

Java, kodu platformdan bağımsız bytecode'a derleyip JVM (Java Virtual Machine) üzerinde çalıştıran, statik tipli, nesne yönelimli bir dildir. Sözdizimi C#'a çok benzer; asıl farklar ayrıntılardadır: checked exception'ları derleyici zorunlu tutar, generic tipler çalışma zamanında silinir (type erasure), `struct`, property ve `async/await` yoktur, LINQ'in yerini Stream API alır. Java 21 ile gelen virtual thread'ler, record'lar, sealed sınıflar ve pattern matching dili belirgin biçimde modernleştirmiştir.

Sayfa bilinen kısmı hızlı geçer, C# geliştiricisinin takılacağı farklara ağırlık verir ve sonunda bir C# → Java hızlı çeviri sözlüğü sunar.

## Sayfadaki ana başlıklar

1. JDK, JRE, JVM ve sürümler (LTS, dağıtımlar)
2. Sözdizimi ve tip sistemi
3. String ve metin
4. OOP: sınıf, arayüz, record, enum
5. Object sözleşmeleri (`equals`/`hashCode`) ve sıralama
6. Generics ve type erasure
7. Koleksiyonlar
8. Stream API (LINQ karşılığı) ve Optional
9. Exception: checked ve unchecked
10. Eşzamanlılık ve virtual threads
11. Modern Java özellikleri, sürüm sürüm
12. I/O, dosya ve serileştirme
13. Tarih ve saat (`java.time`)
14. Annotation, reflection ve kalan konular
15. C# → Java hızlı çeviri sözlüğü
