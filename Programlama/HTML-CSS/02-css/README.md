# CSS

CSS (Cascading Style Sheets), HTML öğelerinin nasıl görüneceğini ve sayfada nasıl yerleşeceğini belirleyen stil dilidir. Adındaki "cascade", aynı öğeye birden çok kural uyduğunda hangisinin kazanacağını belirleyen sistemi anlatır; kaynak sırası, özgüllük (specificity) ve önem (`!important`) birlikte değerlendirilir. Modern düzenin temeli tek eksenli Flexbox ile iki eksenli Grid'dir. Özel değişkenler (custom properties), container query'ler ve `:has()` gibi yeni özellikler CSS'i eskisinden çok daha güçlü kılar.

Sayfa Flexbox ve Grid'i gerçekten öğrenmeye, animasyonlara, değişkenlere ve büyük projede CSS'i yönetme yaklaşımlarına (BEM, CSS Modules, Tailwind ve alternatifleri) odaklanır.
