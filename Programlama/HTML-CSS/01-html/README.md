# HTML

HTML (HyperText Markup Language), web sayfasının iskeletini ve anlamını tanımlayan işaretleme dilidir. Etiketler yalnızca görünüş için değil, içeriğin ne olduğunu anlatmak için seçilir: `<header>`, `<nav>`, `<main>`, `<article>`, `<button>` gibi semantik etiketler hem ekran okuyuculara hem arama motorlarına sayfanın yapısını anlatır. Formlar, `required` ve `pattern` gibi özniteliklerle JavaScript yazmadan da doğrulama yapabilir.

Sayfa etiket ezberi yerine semantik yapıya, form doğrulamaya, erişilebilirliğe ve SEO'ya odaklanır. `iframe`, `dialog`, `template` gibi az bilinen etiketler ayrıca işaretlenmiştir.

## Sayfadaki ana başlıklar

1. Belge yapısı ve `<head>`
2. Metin ve içerik etiketleri
3. Semantik yapı
4. Listeler ve tablolar
5. Bağlantı ve medya
6. iframe ve gömme güvenliği
7. Formlar ve girdi türleri
8. Yerleşik doğrulama ve Constraint Validation API
9. Erişilebilirlik (a11y)
10. SEO ve sayfa performansı
11. Global öznitelikler, Web Components ve doğrulama
