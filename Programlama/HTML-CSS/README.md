# HTML ve CSS

Web sayfasının iki temel katmanı: HTML sayfanın yapısını ve anlamını, CSS görünümünü ve düzenini kurar. JavaScript, TypeScript ve React bu iki katmanın üzerine oturduğu için bu bölüm onların ön koşuludur. Amaç etiket ve seçici ezberlemek değil; semantik yapı, erişilebilirlik, form doğrulama, Flexbox/Grid ile düzen ve büyük projede CSS yönetimi gibi temel seviyenin hemen ötesindeki konuları öğrenmektir.

## İçindekiler

- [HTML](01-html/) — Belge yapısı, semantik etiketler, formlar ve yerleşik doğrulama, iframe güvenliği, erişilebilirlik (a11y), SEO ve Web Components.
- [CSS](02-css/) — Cascade ve özgüllük, kutu modeli, konumlandırma, Flexbox, Grid, değişkenler, responsive tasarım, animasyon, modern CSS ve Tailwind gibi araçlar.

HTML anlatım: [index.html](index.html) (bölümün genel bakışı: öğrenme sırası ve bölüm haritası; yerelde tarayıcıda açılır)
