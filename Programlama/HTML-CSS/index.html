Web'in temel katmanı: HTML ve CSS

HTML sayfanın yapısını ve anlamını, CSS görünümünü ve düzenini kurar. JavaScript, TypeScript ve React bu iki katmanın üstüne oturur; bu bölüm onların ön koşuludur.

2 bölüm · Sıralı yol haritası · Anlatım yok

§ 1Neden önce HTML ve CSS?

Tarayıcıda çalışan her arayüz, hangi kütüphaneyle yazılırsa yazılsın, sonunda HTML ve CSS olarak ekrana gelir. React bileşeni HTML üretir; Tailwind sınıfı CSS'e dönüşür. Bu iki katmanı atlayan biri, "neden ortalanmıyor" veya "form neden sayfayı yeniledi" gibi soruların cevabını yanlış yerde arar.

Atlanan katman kaybolmaz; sadece daha pahalı bir yerde önüne çıkar.

Bu liste nasıl kullanılır

Bu bir ders anlatımı değil, araştırma başlıkları listesi. Hiçbir konu burada öğretilmiyor. Her satırda bir terim, o terimi diğerlerinden ayırt etmene yetecek kadar kısa bir not ve mümkün olduğunda resmî dokümanın bağlantısı var. Öğrenmeyi sen yapacaksın: terimi okuyacaksın, bağlantıya gideceksin, sonra o konuyla ilgili en küçük çalışan örneği yazacaksın.

Bilgi

React ile arayüz geliştirmeyi hedefliyorsan bu bölüm, tarayıcı tarafı öğrenme yolunun ilk iki katmanıdır. Devamı olan JavaScript, TypeScript, React ve araçlar JavaScript ve TypeScript bölümünde. Hedefin farklıysa (sunucu taraflı şablon, tasarım/CMS, e-posta şablonu, Angular/Vue) § 2'deki hedef tablosuna bak.

§ 2Öğrenme sırası ve her katmanda ne kadar duracağın

React hedefleyen biri için tarayıcı tarafı geliştirme beş katmandır: HTML, CSS, JavaScript, TypeScript, React. Bu bölüm ilk ikisini kapsar. Her katmanda "bitirmek" diye bir şey yok; bir sonrakine geçmeye yetecek kadar durup ilerlersin, eksikleri sonradan geri dönüp kapatırsın. Hedefin farklıysa sıra ve derinlik de değişir:

Hedef → HTML/CSS'te ne kadar derine, sonra ne
HedefinSıraHTML/CSS derinliği
Frontend / ReactHTML → CSS → JS → TS → ReactAşağıdaki varsayılan yol.
Angular veya VueHTML → CSS → JS → (Angular için TS zorunlu) → çatıVarsayılan yol; sonrası için JS/TS bölümündeki hedef tablosu.
Backend geliştirici, sunucu taraflı şablonlar (Razor, Thymeleaf, Django/Jinja, Blade)HTML → CSS → Bootstrap veya TailwindHTML'de özellikle form, semantik ve erişilebilirlik; CSS temeli + bir çatı yeterli. JS minimal.
Tasarımcı veya içerik/CMS (WordPress vb.)HTML → CSS (derin)Tipografi, responsive, renk/kontrast ve erişilebilirlik derin; JS opsiyonel.
E-posta şablonu hazırlayanHTML → e-postaya özgü CSSAyrı bir dal: e-posta istemcilerinde modern CSS (flex/grid, custom property) desteği kısıtlıdır; tablo tabanlı düzen ve satır içi (inline) stil gerekir. Destek durumu için caniemail.com.

Aşağıdaki adımlar ve süreler, React hedefleyen ve temel HTML/CSS'i olan biri için önerilen varsayılan yoldur; asıl ölçüt her adımın "Çıktı" satırıdır.

  1. HTML — yapıyı kur

    Temel etiketler çoğu kişinin zaten bildiği kısımdır. Asıl iş semantik etiketler, form ve girdi tipleri, erişilebilirlik ve meta etiketleri. HTML sayfasındaki listede bilmediğin satırları işaretle; hepsini araştırmaya çalışma, sadece işaretlediklerini araştır.

    Çıktı: JavaScript'siz, düzgün semantik ve doğrulamalı bir form sayfası
  2. CSS — düzeni kur

    En çok zaman isteyen iki konu flexbox ve grid. Bunlar oturmadan React'a geçersen "neden ortalanmıyor" sorusuyla saatler kaybedersin. Özgüllük (specificity) konusunu atlarsan !important bağımlısı olursun. CSS sayfası.

    Çıktı: Mobil ve masaüstünde düzgün duran, iki sütunlu bir sayfa · medya sorgusuyla
  3. Sonraki adım — JavaScript

    Yapı ve görünüm oturduktan sonra davranış gelir. Devamı JavaScript ve TypeScript bölümünde: JavaScript → TypeScript → React → araçlar.

    Çıktı: Aynı sayfanın JavaScript ile etkileşimli hâli

§ 3Temel etiket ve seçicilerin hemen ötesi

Çoğu kişi HTML'de a, img, alt, href; CSS'te class/id seçici ve arka plan rengi düzeyinde başlar. Bu iyi bir başlangıçtır: iki katmanın da giriş kapısı açıktır. Aşağıdaki iki tablo, bu temelden hemen sonra gelen başlıklardır; ayrıntılı listeler bölüm sayfalarında. Seviyen farklıysa:

  • Hiç bilmiyorsan → önce MDN "Learn web development" (HTML/CSS temelleri) veya web.dev Learn HTML / Learn CSS; bu tablolar ikinci adım.
  • Temel etiket ve seçicileri biliyorsan → doğrudan aşağıdaki tablolar.
  • Bootstrap/Tailwind ile çalıştın ama saf CSS'in zayıf → doğrudan özgüllük (specificity), kutu modeli, flexbox ve grid satırlarına git.
  • Orta–ileri seviyedeysen → 01 ve 02 sayfalarının ORTA/İLERİ satırları (container query, :has(), @layer, erişilebilirlik testleri).

§ 5Özet: bu sayfadan çıkarılacak sıra

  1. Sıra (React/Angular/Vue hedefi): HTML → CSS → JavaScript

    HTML kısa sürer, CSS daha uzun; ikisi de JavaScript'ten önce gelir. Sunucu taraflı şablon yazan backend geliştiricisi için HTML/CSS + bir çatı (Bootstrap/Tailwind) yeterli, JS minimal; tasarımcı/CMS için CSS derinleşir, JS opsiyonel; e-posta şablonunda modern CSS yerine tablo düzeni ve satır içi stil gerekir. § 2.

  2. Konuyu doğru katmanda ara

    Responsive, animasyon ve koyu tema CSS'in; form doğrulamanın ilk adımı ve erişilebilirlik HTML'in konusudur. Kütüphane aramadan önce § 2'deki "hangi konu hangi katmana ait" tablosuna bak.

  3. Mülakatta sık sorulanları kapat

    HTML'de semantik etiketler, form doğrulama ve erişilebilirlik; CSS'te özgüllük, flexbox ve position/z-index. İş ilanlarında HTML5, CSS3 ve Bootstrap sık geçer; her biri için elinde en az bir çalışan örnek olmalı.

  4. Her katmanı bir çıktıyla kapat

    Okumak yetmez. § 2'deki "Çıktı" satırında yazan küçük sayfayı yaz; aynı sayfayı sonra JavaScript ile büyüt.

  5. Çatıyı (Bootstrap, Tailwind) saf CSS temelinden sonraya bırak

    Saf CSS'i bilmeden çatı öğrenmek sınıf ezberine dönüşür. Ekibin veya projen bir çatı kullanıyorsa temel (kutu modeli, flexbox, grid, özgüllük) oturur oturmaz o çatıya geç; kullanmıyorsa en sona bırak. Ayrıntı CSS sayfasında.
