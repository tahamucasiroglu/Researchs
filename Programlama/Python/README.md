# Python

Python, okunabilirliği ön planda tutan, dinamik tipli, yorumlanan bir dildir. Bloklar süslü parantezle değil girintiyle belirlenir. Geniş standart kütüphanesi ve paket ekosistemi sayesinde otomasyon ve betik yazımından web geliştirmeye (Django, Flask, FastAPI), veri analizinden (NumPy, Pandas) makine öğrenmesi ve derin öğrenmeye (scikit-learn, TensorFlow, PyTorch) kadar çok farklı alanda kullanılır. CPython'daki GIL nedeniyle CPU ağırlıklı paralel işlerde `multiprocessing`, G/Ç ağırlıklı işlerde `asyncio` tercih edilir.

Sayfa, dil temellerinden veri bilimi ve yapay zeka kütüphanelerine, web çatılarından test araçlarına kadar Python ekosisteminde aranacak terimleri sıralar. İş ilanlarında ve mülakatlarda sık geçen konular ayrıca işaretlenmiştir.
