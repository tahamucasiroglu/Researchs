# React

React, kullanıcı arayüzünü bileşenlerden (component) kuran bir JavaScript kütüphanesidir. Her bileşen, aldığı props ve kendi state'ine göre JSX ile ne çizileceğini tarif eden bir fonksiyondur. State değişince React bileşeni yeniden çalıştırır (render) ve gerçek DOM'a yalnızca gereken farkları uygular. `useState`, `useEffect`, `useMemo` gibi hook'lar fonksiyon bileşenlerine durum ve yan etki yönetimi kazandırır.

Sayfa temel kavramlardan bütün hook'lara, performans optimizasyonundan yaygın kalıp ve hatalara kadar her başlığı bir araştırma sorgusu olarak sıralar; sırayla ilerlemek için tasarlanmıştır.
