# TypeScript

TypeScript, JavaScript'e statik tip sistemi ekleyen ve derlendiğinde düz JavaScript'e dönüşen bir dildir; tipler yalnızca derleme zamanında vardır, çalışma zamanında silinir. Sözdizimi C#'a benzese de temel bir fark vardır: TypeScript **yapısal tipleme** kullanır. İki tipin uyumlu sayılması için aynı adı taşıması değil, aynı şekle (aynı alanlara) sahip olması yeterlidir. Union tipler, tip daraltma (narrowing), generics ve `Partial`, `Pick` gibi utility type'lar dilin gücünü oluşturur.

Sayfa benzerlikleri hızlı geçer, farklara ve pratik kullanıma (React, API tipleri, Zod gibi araçlarla çalışma zamanı doğrulaması) odaklanır.

## Sayfadaki ana başlıklar

1. Temel tipler
2. Tip sistemi ve daraltma
3. Fonksiyon ve sınıf tipleri
4. Generics
5. İleri tipler ve utility types
6. Modüller, `tsconfig` ve tip tanım dosyaları
7. Decorator ve metadata
8. Araçlar: derleme, lint, test
9. Pratik: React, API tipleri, runtime doğrulama
10. C# geliştiricisinin takıldığı yerler
