Image-to-Pixel: görseli piksel sanatına çevirmek

Tarayıcıda ve Node.js'te çalışan, MIT lisanslı piksel sanatı motoru. Ne yapıyor, ticari kullanılır mı, bir .NET masaüstü video aracına nasıl bağlanır, alternatifleri neler.

Image-to-Pixel 3.0.1 · MIT · 15.10.2026

§ 0Özet

Kısa cevap

  • Ne: JavaScript motoru + editör: 24 palet, 16 dithering yöntemi, PNG/GIF/WebM/MP4, toplu işlem (§ 2).
  • Ticari: MIT, tek bağımlılığı da MIT. Yalnız telif/izin notu korunur (§ 6).
  • .NET masaüstü için: gömmek yerine algoritmayı SkiaSharp ile yazmak + video için ffmpeg paletteuse=dither=bayer. JS/Remotion hattında paket doğrudan kullanılır (§ 7).

§ 1Terimler

  • Piksel sanatı: az sayıda büyük, keskin piksel ve sınırlı renkle yapılan retro görünüm.
  • Palet: kullanılabilecek sabit renk listesi (ör. PICO-8'in 16 rengi).
  • Dithering: az renkle ara tonları taklit etmek için pikselleri desenli dağıtmak.
  • Bayer (sıralı): sabit eşik matrisiyle dithering; kareden kareye kararlı.
  • Hata dağıtımı: Floyd–Steinberg, Atkinson vb.; her pikselin renk hatası komşulara aktarılır.
  • OKLab: algıya göre düzenlenmiş renk uzayı; "en yakın renk" seçimi daha doğru olur.
  • WebCodecs: tarayıcının yerleşik video kodlama/çözme arayüzü.

§ 3İşlem hattı

  1. prep: küçült, ton ayarları, saydamlık kesimi.
  2. quant: sıralı eşik + en yakın palet rengi (OKLab).
  3. diffuse: hata dağıtımı.
  4. resolve → orphan + smooth temizlik → out dış çizgi.

Hata dağıtımı GPU'da nasıl paralel olur?

Floyd–Steinberg sıralıdır. Proje "dalga" (wavefront) yöntemi kullanıyor: çekirdeğin her ofseti hatayı daha sonraki x + s·y dalgasına iter, böylece aynı dalgadaki pikseller bağımsız hesaplanır (Floyd–Steinberg/Atkinson için s=2, Jarvis/Stucki/Burkes için s=3). 96×64 görsel 222 çizim alır. CPU yolu shader ile satır satır aynı yazıldığı için iki yol bit düzeyinde aynı sonucu verir.

§ 4Kütüphane kullanımı

import { createPixelator } from 'image-to-pixel';
const px = await createPixelator();            // 'auto' | 'webgl' | 'cpu'
const r = await px.process(source, {
  size: { width: 128 },
  palette: { source: 'builtin', id: 'pico-8' },
  dither: { method: 'floyd-steinberg', strength: 0.8 },
});
const png = await r.toPNG({ scale: 8 });

Node.js'te CPU arka ucu çalışır: görseli başka bir kütüphaneyle çözüp { width, height, data } (ham RGBA) verirsin. PNG, GIF ve ZIP kodlayıcıları DOM istemez.

§ 9Durum → sonuç

  • JS/web projesi → paketi doğrudan kullan.
  • .NET masaüstü, tek görsel → algoritmayı SkiaSharp ile yaz; bu projeyi başvuru kaynağı yap.
  • Video efekti, ffmpeg zaten var → paletteuse=dither=bayer zinciri.
  • Hazır .NET kütüphanesi, ciro < 1M $ → ImageSharp; büyüme ihtimali varsa Magick.NET.
  • Oyun için sprite sheet / tileset → bu araç doğrudan uygun.
