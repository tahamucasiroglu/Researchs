# JavaScript

JavaScript, web tarayıcılarının yerleşik dilidir; Node.js sayesinde sunucuda da çalışır. Dinamik tiplidir, fonksiyonlar birinci sınıf değerdir ve nesne modeli sınıflara değil prototiplere dayanır (`class` sözdizimi bunun üzerine eklenmiş bir kolaylıktır). Tek iş parçacığında çalışır; asenkron işler event loop, Promise ve `async/await` ile yönetilir. C# bilen biri için en çok şaşırtan konular `this` bağlamı, truthy/falsy değerler, `==` ile `===` farkı, hoisting ve closure'lardır.

Sayfa dili sıfırdan, kategorilere ayırarak anlatır; C# karşılığı olan kavramlar ayrıca işaretlenmiştir.
