# JavaScript ve TypeScript

Tarayıcıda ve Node.js üzerinde çalışan JavaScript, onun üzerine statik tip ekleyen TypeScript ve en yaygın arayüz kütüphanesi React için sıralı bir öğrenme yolu. Temel fikir şudur: React bir JavaScript kütüphanesidir; JavaScript bilmeden React'a atlamak, bir şey bozulduğunda tıkanmak demektir. Bu yüzden sıra JavaScript → TypeScript → React → ekosistemdir. C# bilen biri için tanıdık ve yeni kavramlar ayrıca işaretlenmiştir. HTML ve CSS bu bölümün ön koşuludur ve [HTML-CSS](../HTML-CSS/) bölümünde anlatılır.

## İçindekiler

- [JavaScript](01-javascript/) — Dil çekirdeği, fonksiyonlar ve closure, prototip ve class, asenkron JavaScript ve event loop, DOM, tarayıcı API'leri, modüller, modern ES sürümleri ve güvenlik.
- [TypeScript](02-typescript/) — Temel tipler, yapısal tipleme ve daraltma, generics, utility type'lar, `tsconfig`, decorator'lar ve C# geliştiricisinin takıldığı yerler.
- [React](03-react/) — Bileşen, props, state ve render döngüsü, hook'ların tamamı, Context, performans, formlar, veri çekme, yönlendirme, React 18/19 özellikleri ve test.
- [Ekosistem ve Araçlar](04-ekosistem-ve-araclar/) — Paket yöneticileri, Vite ve derleme araçları, Next.js gibi meta-framework'ler, state yönetimi, UI kütüphaneleri, test, kod kalitesi, dağıtım ve .NET ile entegrasyon.
- [Kütüphaneler](kutuphaneler/) — Çalışılan npm kütüphaneleri, her biri kendi klasöründe. İlk: [Image-to-Pixel](kutuphaneler/image-to-pixel/) — görselleri ve videoları piksel sanatına çeviren MIT lisanslı motor.

HTML anlatım: [index.html](index.html) (bölümün genel bakışı: katman sırası ve her katmanda ne kadar durulacağı; yerelde tarayıcıda açılır)
