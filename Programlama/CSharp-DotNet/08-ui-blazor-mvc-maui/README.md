# Blazor, MVC ve MAUI

.NET yalnızca sunucu tarafında değil, arayüz tarafında da kullanılabilir. **ASP.NET Core MVC**, Razor sözdizimiyle sunucuda HTML üreten klasik model-view-controller çatısıdır. **Blazor**, C# ile bileşen tabanlı web arayüzleri yazmayı sağlar; bileşenler sunucuda (interaktif sunucu render) ya da tarayıcıda WebAssembly üzerinde çalışabilir. **.NET MAUI** tek kod tabanıyla Android, iOS, Windows ve macOS uygulamaları geliştirmeye yarar; masaüstünde ise WPF, WinForms ve çok platformlu **Avalonia** gibi seçenekler bulunur.

Bu sayfa sunucu tarafı render'dan WebAssembly'ye, mobilden masaüstüne bu çatıları ve istemci tarafı mimari desenlerini (MVVM vb.) listeler; Flutter bilenler için kavram karşılıkları tablosu da içerir.

## Sayfadaki ana başlıklar

- Razor: sözdizimi ve view katmanı
- ASP.NET Core MVC
- Blazor: barındırma modelleri ve render modes
- Blazor: bileşen modeli ve yaşam döngüsü
- Blazor: form, routing, state, güvenlik, performans
- Blazor UI kütüphaneleri
- .NET MAUI
- Flutter bilgisini MAUI'ye çevirme tablosu
- Masaüstü çatıları
- İstemci tarafı mimari desenleri
- Web arayüzü köprüsü: nereye kadar .NET, nereden sonra JavaScript
