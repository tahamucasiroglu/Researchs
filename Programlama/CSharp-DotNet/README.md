# C# ve .NET

C# ve .NET ekosistemi için bir "anahtar liste": her bölüm, bir alanda neyin araştırılması gerektiğini başlık başlık sıralar ve resmî dokümanlara yönlendirir. Öncelik sırası, iş ilanlarında ve mülakatlarda en sık geçen teknolojilere göre kurulmuştur. Dilin kendisinden Web API'ye, veri erişiminden mimariye, test ve DevOps'tan arayüz çatılarına kadar on bölümden oluşur.

## İçindekiler

- [C# Dili](01-csharp-dili/) — Temel sözdiziminden C# 12–14 yeniliklerine kadar dil özellikleri: OOP, generics, LINQ, async, pattern matching, bellek ve performans.
- [Platform ve Web API](02-platform-ve-web-api/) — .NET runtime, hosting, dependency injection, configuration, middleware, routing ve ASP.NET Core ile Web API geliştirme; kimlik doğrulama dahil.
- [Veri Erişimi](03-veri-erisimi/) — EF Core, Dapper, SQL Server, NoSQL veritabanları, Redis ve önbellekleme stratejileri; sorgu performansı ve migration.
- [Mimari ve Desenler](04-mimari-ve-desenler/) — SOLID, katmanlı ve Clean mimari, CQRS, MediatR, DDD, event sourcing, GoF desenleri ve mikroservis kavramları.
- [Mesajlaşma ve Dağıtık Sistemler](05-mesajlasma-ve-dagitik/) — RabbitMQ, MassTransit, outbox deseni, gRPC, SignalR, arka plan işleri ve dağıtık sistem teorisi.
- [Test ve Kod Kalitesi](06-test-ve-kalite/) — Birim ve entegrasyon testi, mock kavramı, test çatıları, TDD/BDD, BenchmarkDotNet ve statik analiz araçları.
- [DevOps ve Gözlemlenebilirlik](07-devops-ve-gozlemlenebilirlik/) — İleri Git, GitHub Actions, Azure DevOps, Docker, Kubernetes temelleri, loglama ve OpenTelemetry ile izleme.
- [Blazor, MVC ve MAUI](08-ui-blazor-mvc-maui/) — .NET'in arayüz tarafı: Razor, ASP.NET Core MVC, Blazor, .NET MAUI ve Avalonia gibi masaüstü çatıları.
- [Aspire, Bulut ve Modern .NET](09-aspire-bulut-modern/) — .NET Aspire, .NET sürüm ve destek takvimi, Native AOT, bulut yerel kavramlar ve .NET'te yapay zekâ.
- [Kütüphaneler](10-kutuphaneler/) — Kategori kategori yaygın NuGet kütüphaneleri ve lisans durumları; denenen kütüphanelerin (Redis, RabbitMQ vb.) çalışmaları da burada toplanır.

HTML anlatım: [index.html](index.html) — genel bakış ve önerilen çalışma sırası (yerelde tarayıcıda açılır).
