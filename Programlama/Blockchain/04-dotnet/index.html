Bölüm 04 · Ekosistemler

.NET ile blockchain: Nethereum ve ötesi

.NET'in blockchain'deki yeri tarayıcı değil, arka plan: zinciri dinleyen, olayları indeksleyen, imza atan, cüzdan yöneten servisler. ASP.NET Core ile birleşen kısım burası; JavaScript ekosisteminin yerini almaz, onu tamamlar.

Seviye: orta · .NET uzmanlığıyla kesişim

§ 1Nethereum — ana kütüphane

Bu sayfa, blockchain'in .NET uzmanlığıyla kesiştiği yer: ASP.NET Core, SQL Server ve mimari konuları C# ve .NET bölümünde; burada yalnızca o bilgiye eklenen zincir tarafı anahtar kelimeleri var. .NET temeli sağlam değilse önce oradan başla. Nethereum, .NET için Ethereum/EVM istemci kütüphanesidir; JavaScript dünyasındaki ethers.js / viem'in C# karşılığıdır (03 — JavaScript/TypeScript sayfasıyla yan yana oku).

  • .NET biliyorsan → bu sayfa blockchain'i ana yetkinliğine bağlayan yerdir; sırayla oku.
  • .NET bilmiyorsan, JS/TS biliyorsan → bu sayfa okuma amaçlıdır; aynı işleri (indeksleyici, SIWE doğrulama, sunucu cüzdanı) 03 § 8 ve § 11'deki Node.js araçlarıyla yaparsın.
  • Java, Python veya Go biliyorsan → desenler (backfill, checkpoint, reorg tamponu, idempotency) dilden bağımsızdır; buradaki kavram adlarını kendi dilindeki kütüphaneyle uygula (Java: web3j, Python: web3.py, Go: go-ethereum ethclient; güncel durumları TEYİT).

Sürüm durumu (13 Eylül 2026 itibarıyla doğrulandı)

Nethereum.Web3 son kararlı sürüm 6.1.0 (25 Mart 2026, NuGet). Hedefler: netstandard 2.0, net451/net461, net6.0, net8.0, net9.0, net10.0; Unity için net461/net472/netstandard 2.1. Yani .NET 8/9/10 projelerinde doğrudan çalışır. Kurulum: dotnet add package Nethereum.Web3. 130'dan fazla paket var; hepsini değil, aşağıdaki çekirdeği öğren.

§ 4Kurumsal / izinli blockchain

Türkiye'deki .NET iş ilanlarında "blockchain" kelimesi çoğunlukla bu başlık altında geçiyor gibi görünür: banka, tedarik zinciri, denetim izi. Bu tespit nicel bir araştırmaya dayanmaz TEYİT; ilan sitelerinde kendin kontrol et. Burada amaç kripto değil, çok taraflı güven. Hangi satırın senin için öncelikli olduğu hedefine bağlı:

  • SQL Server / Azure SQL kullanıyorsan ya da kurumsal (banka, denetim izi) ilan hedefliyorsan → SQL Server ledger tabloları TEMEL; Besu izinli mod ve Confidential Ledger ORTA.
  • PostgreSQL ya da başka veritabanı kullanıyorsan, ya da kamu zinciri (EVM) hedefliyorsan → ledger tablolarını kavram olarak bil (ORTA); öncelik § 1–2.
  • Kurumsal ilan Java veya Go istiyorsa → Fabric (chaincode Go/Java/Node) ve Besu; ayrıntı 05 § 12.

§ 9Özet: bu sayfadaki öncelik sırası

  • Önce mülakatta sık sorulanı savunabil: ContractHandler, Function/Event DTO ve codegen — Solidity sözleşmesini .NET'ten çağırabildiğini Playground'da 1 saatte göster (§ 1b).
  • Çekirdek Nethereum: Web3, Account, TransactionManager, EIP-1559 fee, HexBigInteger/UnitConversion, eth_getLogs (§ 1a). Nethereum.Web3 6.1.0, .NET 8/9/10 uyumlu.
  • Anahtar ve imza: EthECKey, KeyStore, HdWallet, EIP-191 mesaj imzası, EIP-712 (§ 1c). KMS/HSM paketlerini kavram olarak bil, ücretli oldukları için kurmana gerek yok.
  • Backend deseni (.NET geliştiricisi için en güçlü alan): BackgroundService + BlockchainProcessing (LogOrchestrator, progress repo, reorg tamponu, 12 onay) → BlockchainStore.Postgres / .SqlServer / .Sqlite (§ 2a). .NET backend ilanlarını hedefliyorsan portföydeki en inandırıcı .NET+blockchain parçasıdır; JS/TS hattındaysan aynı rolü Ponder/viem indeksleyici oynar (03).
  • Kimlik doğrulama: SIWE (EIP-4361) endpoint'i Nethereum.Siwe ile; nonce, domain, expiration olmadan yapma (§ 2b).
  • Güvenilir gönderim: nonce eşzamanlılığı, stuck tx, Polly, idempotency, outbox — DotNet 05 konularını biliyorsan bilgin doğrudan geçer (§ 2c).
  • Tuzaklar: Keccak-256 ≠ SHA3_256; BigInteger little-endian; ECDsa secp256k1 değil; wei için decimal/double yok (§ 5).
  • Kurumsal kesişim: SQL Server ledger tabloları ve Azure Confidential Ledger — SQL Server kullanıyor ya da kurumsal ilan hedefliyorsan öncelikli; diğer durumlarda kavram olarak bil (§ 4). GoQuorum ve Azure Blockchain Service eskidi.
  • Diğer zincirler: NBitcoin + BTCPay Server kaynak kodu okumak yeter; Solnet, Neo, Netezos, Substrate.NET.API isim düzeyinde (§ 3).
  • Test: Nethereum.DevChain veya anvil + xUnit + Testcontainers; snapshot/revert ile izolasyon (§ 8).
  • Eskimiş, öğrenme: ManagedAccount/personal_ API, OpenZeppelin Defender, WalletConnectSharp, GoQuorum, Azure Blockchain Service, TypeChain (legacy), Holesky.
  • Sıfır bütçe yolu: Playground → DevChain → anvil → Sepolia faucet. Alchemy/Infura ücretsiz katmanı yeter; mainnet'e para koyma.
