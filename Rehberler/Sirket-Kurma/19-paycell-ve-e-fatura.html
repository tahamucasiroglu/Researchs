Ödeme altyapısı · e-Belge API

Paycell ile ödeme almak, test ortamları ve e-Şirket API

Paycell: Turkcell grubunun lisanslı ödeme kuruluşu (sanal POS, link, fiziki POS). e-Şirket: e-Fatura/e-Arşiv REST API'si. Arada: sağlayıcıların test ortamları ve ödeme akışı.

Araştırma: 12 Ekim 2026 · Kaynak: resmî sayfalar + işaretli 3. taraf · Rakamlar değişir

Hukuki / mali danışmanlık değildir

Koşullar okurun durumuna göre değişir. Başvurudan önce sağlayıcıdan, vergisel sonucu mali müşavirden teyit et. Fiyatlar araştırma tarihindeki hâlidir.

Etiketler: RESMİ sağlayıcının kendi sayfası · 3. TARAF entegratör/haber/blog · TAHMİN çıkarım · DOĞRULANMADI Eylül 2026 notundan, bu tarihte resmî kaynakta teyit edilemedi · BİLİNMİYOR resmî kaynakta yok.

§ 1Paycell nedir, lisansı

  • İşleten: Turkcell Ödeme ve Elektronik Para Hizmetleri A.Ş. — 6493 sayılı Kanun'a tabi, TCMB lisanslı (2020 öncesi BDDK).
  • Tarihçe: 2016 ödeme kuruluşu, 2017 e-para kuruluşu izni; Mart 2025'te TCMB izin kapsamını genişletti 3. TARAF.
  • Bireysel taraf: cüzdan, Paycell Kart, IBAN/numaraya para gönderme-isteme, QR, "Faturana Yansıt" RESMİ.
  • Anlamı: Banka değil ama sanal POS'u kendi adına sunar → tek entegrasyonla bütün bankaların kartları.

§ 4Başvuru ve belgeler

  1. Kanal seç

    İştePaycell uygulaması · kurumsal destek · hazır e-ticaret altyapısının "Paycell" sekmesi

  2. Form

    Firma bilgisi, faaliyet alanı, site adresi, aylık planlanan hacim (3. taraf)

  3. Kimlik doğrulama

    Uygulama içinden (RESMİ); belge listesi yayımlanmamış

  4. Site denetimi

    HTTPS, iletişim, mesafeli satış sözleşmesi, iade koşulları, KVKK metni (genel uygulama, 3. taraf)

  5. Sözleşme → canlı

    Bir entegratör "24 saatte satışa başlama" diyor (3. taraf)

§ 9Ödeme sayfası akışı (genel, 3D Secure)

Türk sanal POS sağlayıcılarının çoğunda aynı iskelet. Adlar sağlayıcıya göre değişir; Paycell'e özgü değildir.

Renk: Müşteri Senin sunucun Ödeme sağlayıcı Kartı veren banka

  1. 1 · SepetMüşteri "Öde"ye basar.Müşteri
  2. 2 · Ödeme başlatSunucu tutar + sipariş no + dönüş URL'siyle sağlayıcıya istek atar. Gizli anahtar yalnız sunucuda.Sunucu
  3. 3 · Ödeme formuSağlayıcının sayfası/iframe'i kart bilgisini alır; kart senin sunucuna değmez.Sağlayıcı
  4. 4 · 3D SecureBanka SMS şifresiyle doğrular.Banka
  5. 5 · DönüşTarayıcı dönüş URL'sine gelir; ayrıca webhook/bildirim gelebilir.Sağlayıcı
  6. 6 · DoğrulaDönüşe güvenme: imzayı doğrula veya sorgu ucuyla sonucu çek, tutarı karşılaştır.Sunucu
  7. 7 · Sipariş + faturaSiparişi onayla; e-Arşiv faturayı kes (§ 14).Sunucu

Sık hata

  • Sonucu yalnız tarayıcı dönüşüne bakarak onaylamak → sahte dönüşle sipariş onaylatılabilir. Sunucu tarafında doğrula.
  • Aynı bildirimi iki kez işlemek → sipariş no ile tekil (idempotent) işle.
  • Kart numarasını kendi sunucundan geçirmek → PCI DSS yükü. Sağlayıcının formunu/token'ını kullan.

§ 11Entegrasyon adımları (sağlayıcıdan bağımsız)

  1. Ödeme arayüzü tanımla

    Ödeme başlat · sonucu doğrula · iade/iptal · abonelik durumu → tek arayüz; her sağlayıcı ayrı adaptör

  2. Sandbox anahtarı al

    Ortam değişkenine koy; test ve canlı anahtarı ayrı tut (Craftgate gibi ortamlarda karışınca çalışmaz)

  3. Ödeme başlat + dönüş URL'si

    Sipariş no = tekil anahtar; tutarı sunucuda hesapla

  4. Webhook / sorgu ile doğrula

    İmza doğrulama; aynı olayı iki kez işleme

  5. Test kartlarıyla senaryolar

    Başarılı · yetersiz bakiye · 3D başarısız · iade · kısmi iade · abonelik yenileme hatası

  6. Canlı başvurusu

    Şirket belgeleri + site denetimi (§ 4); canlı anahtarla küçük tutarlı gerçek deneme

§ 16C# örneği (.NET, HttpClient + System.Text.Json)

Gönder → durumu sorgula (webhook olmadığı için). Anahtar ve taban adres ortam değişkeninden.

using System;
using System.Net;
using System.Net.Http;
using System.Net.Http.Json;
using System.Threading.Tasks;
using System.Text.Json;
using System.Text.Json.Serialization;

// ESIRKET_BASE_URL: test için https://efaturaservicetest.isim360.com
var http = new HttpClient { BaseAddress = new Uri(
    Environment.GetEnvironmentVariable("ESIRKET_BASE_URL")
    ?? "https://efaturaservicetest.isim360.com") };
http.DefaultRequestHeaders.Add("X-Api-Key",
    Environment.GetEnvironmentVariable("ESIRKET_API_KEY")
    ?? throw new InvalidOperationException("ESIRKET_API_KEY yok"));

var istek = new
{
    recordType = 0,
    status = 20,
    localReferenceId = "SIP-0001",
    addressBook = new
    {
        name = "Örnek", receiverPersonSurName = "Müşteri",
        identificationNumber = Environment.GetEnvironmentVariable("ORNEK_ALICI_NO"),
        receiverDistrict = "{ILCE}", receiverCity = "{IL}", receiverCountry = "Türkiye",
        receiverEmail = "{ALICI_EPOSTA}"
    },
    generalInfoModel = new
    {
        invoiceProfileType = 4, type = 1,
        issueDate = DateTime.Now.ToString("yyyy-MM-dd'T'HH:mm:ss"),
        currencyCode = "TRY"
    },
    invoiceLines = new[]
    {
        new { inventoryCard = "Örnek Hizmet", amount = 1m, unitCode = "C62",
              unitPrice = 1000m, vatRate = 20m }
    },
    archiveInfoModel = new { IsInternetSale = true, websiteUrl = "https://{ALAN_ADI}",
                             shipmentSendType = "ELEKTRONIK" },
    eArsivInfo = new { sendEMail = true }
};

// 1) Gönder
var cevap = await http.PostAsJsonAsync("/v2/earchive/create", istek);
if (cevap.StatusCode == HttpStatusCode.UnprocessableEntity)
    throw new Exception("Doğrulama hatası (tekrar gönderme): "
        + await cevap.Content.ReadAsStringAsync());
cevap.EnsureSuccessStatusCode();
var olusan = await cevap.Content.ReadFromJsonAsync<Olusan>();

// 2) Durumu sorgula: 60 = onaylandı, 40 = hata, 100 = iptal
var json = new JsonSerializerOptions(JsonSerializerDefaults.Web);
for (var deneme = 0; deneme < 20; deneme++)
{
    await Task.Delay(TimeSpan.FromSeconds(15));
    var r = await http.GetAsync($"/v2/earchive/{olusan!.Id}/status");
    if (r.StatusCode == HttpStatusCode.TooManyRequests) continue; // 429: limit
    r.EnsureSuccessStatusCode();
    var d = await r.Content.ReadFromJsonAsync<Durum>(json);
    if (d!.Status is 60 or 40 or 100)
    {
        Console.WriteLine($"{d.InvoiceNumber}: {d.Status} {d.Message}");
        break;
    }
}

record Olusan([property: JsonPropertyName("Id")] Guid Id,
              [property: JsonPropertyName("InvoiceNumber")] string InvoiceNumber);
record Durum(Guid Id, string? InvoiceNumber, int Status, string? Message);
  • Bearer yolu: POST /v1/token'a FormUrlEncodedContent ile username/password/client_id=serviceApi gönderilir; cevap alan adları belgede yazmıyor → test ortamında bak, 401'de yeniden al.
  • Sorgu aralığını limitlere göre seç (§ 17); gelen fatura listesi 15 dakikada 6 istekle sınırlı.
