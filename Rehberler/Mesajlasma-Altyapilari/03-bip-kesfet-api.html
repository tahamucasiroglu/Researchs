BiP Keşfet API (TES): uç nokta, JSON, C#

BiP'te kurumlar "Keşfet" altında servis (kanal) açar. TES bu servisin REST API'sidir: gönder, takipçi listele, gelen mesajı ve iletildi/okundu raporunu kendi HTTPS ucunda al.

Okuma ~10 dk · Seviye: teknik · Araştırma: 12 Ekim 2026

§ 8C# örneği (.NET, HttpClient + System.Text.Json)

Kimlik bilgileri ortam değişkeninden: BIP_TES_USER, BIP_TES_PASS. Alıcı adresi örnekte MSISDN; servisiniz hash adresle çalışıyorsa type: 0.

Gönderme

// Konsol projesi (.NET 8+), top-level statements
using System;
using System.Net.Http;
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Text;
using System.Text.Json;

var user = Environment.GetEnvironmentVariable("BIP_TES_USER")!;
var pass = Environment.GetEnvironmentVariable("BIP_TES_PASS")!;

var http = new HttpClient { BaseAddress = new Uri("https://tims.turkcell.com.tr/tes/rest/spi/") };
http.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue(
    "Basic", Convert.ToBase64String(Encoding.UTF8.GetBytes($"{user}:{pass}")));

var istek = new
{
    txnid = Guid.NewGuid().ToString("N"),            // her istekte yeni, en çok 40 karakter
    receiver = new { type = 2, address = "905XXXXXXXXX" },
    composition = new { list = new object[] { new { type = 0, message = "Siparişiniz hazırlandı." } } }
};

using var yanit = await http.PostAsJsonAsync("sendmsgserv", istek);
var govde = await yanit.Content.ReadFromJsonAsync<JsonElement>();

if (yanit.StatusCode == System.Net.HttpStatusCode.BadRequest)
    Console.WriteLine($"Doğrulama hatası: {govde.GetProperty("errorcode")} {govde.GetProperty("errordefinition")}");
else
{
    // resultcode belgede "string" yazıyor ama örneklerde sayı: ikisini de kabul et
    var rc = govde.GetProperty("resultcode");
    var kod = rc.ValueKind == JsonValueKind.Number ? rc.GetInt32() : int.Parse(rc.GetString()!);
    Console.WriteLine(kod switch
    {
        0   => "Kabul edildi",
        312 => "Kota doldu ya da kullanıcının açık oturumu yok",
        310 => "txnid tekrarlandı",
        _   => $"Hata: {kod}"
    });
}

Geri besleme ucu (ASP.NET Core minimal API)

// Web projesi (Microsoft.NET.Sdk.Web, .NET 8+)
using System;
using System.Text.Json;
using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;

var app = WebApplication.CreateBuilder(args).Build();

// Operasyon ekibine bildirilen URL: https://{ALAN_ADINIZ}/bip
app.MapPost("/bip", async (HttpRequest req) =>
{
    var olay = await JsonSerializer.DeserializeAsync<JsonElement>(req.Body);
    var tur = olay.GetProperty("type").GetString();

    switch (tur)
    {
        case "M":
            var ctype = olay.GetProperty("ctype").GetString();
            if (ctype == "T")
                Console.WriteLine($"Metin: {olay.GetProperty("content").GetString()}");
            else if (ctype == "Postback")
                Console.WriteLine($"Düğme: {olay.GetProperty("postback").GetProperty("payload").GetString()}");
            else if (ctype == "Poll")
                Console.WriteLine($"Anket: {olay.GetProperty("poll").GetProperty("optionids")}");
            break;
        case "E":
            Console.WriteLine(olay.GetProperty("event").GetString() == "S" ? "Takip etti" : "Takibi bıraktı");
            break;
        case "R":
            Console.WriteLine($"Rapor: {olay.GetProperty("report").GetProperty("reportid").GetString()}");
            break;
    }
    // Gönderen kimliği: olay.GetProperty("sender") — hash ya da MSISDN; kişi eşleştirmeyi numaraya bağlama.
    return Results.Ok();                               // hızlı 200; ağır işi kuyruğa at
});

// Eş zamansız gönderim sonuçları
app.MapPost("/bip/report", async (HttpRequest req) =>
{
    var rapor = await JsonSerializer.DeserializeAsync<JsonElement>(req.Body);
    foreach (var a in rapor.GetProperty("list").EnumerateArray())
        Console.WriteLine($"{a.GetProperty("resultcode")} → {a.GetProperty("reportid")}");
    return Results.Ok();
});

app.Run();

Kısmi REXEşleşme yoksa mesaj sizin TES entegre web servisinize gider.
Müşteri hizmetleriAIML'de bip_callcenter (temsilciye aktar, host = dış WS URL), bip_exitpattern (bota dön), bip_callcenter_result (true/false).
Dış sisteme aktarımREX yazışmaları toplu (liste) halinde dış web servisinize POST edilir. HTTP'de kimlik doğrulama yok, HTTPS'te Basic Auth. Müşteri hizmetleri yazışmaları aktarılmaz.

Dış sisteme aktarım — gövde (resmî örneğin sadeleştirilmiş hâli)

{
  "list": [ {
    "request": {
      "msgId": "1", "transactionId": "1", "serviceId": 1234,
      "receiveDate": "12/10/2026 08:00:00",
      "sender": "905XXXXXXXXX", "type": "M",
      "content": { "type": 0, "message": "destek" }
    },
    "response": {
      "composition": { "list": [ { "type": 0, "message": "Temsilciye bağlanıyorsunuz." } ] }
    }
  } ]
}

request.content — düğme cevabı

{ "type": 103, "tmmType": 3, "tmmPostbackResponse": { "payload": "…", "postbackid": "…" } }

request.content — anket cevabı

{ "type": 104, "tmmType": 2, "tmmPollResponse": { "pollid": "…", "optionids": [1, 3] } }

serviceId resmî örnekte sayı (burada yer tutucu 1234); msgId ve transactionId metin.

Dikkat: REX aktarımında alan adları camelCase (tmmType, tmmSingle), TES gönderiminde küçük harf (tmmtype, singletmm).

§ 18Tuzaklar ve başvuruda sorulacaklar

  • 200 ≠ gönderildi: eş zamansız gönderimde sonuç /report'a gelir; dinlemeyen sistem hatayı göremez.
  • Oturum düşmesi: destek/sipariş akışı 312 ile kesilir; kullanıcıdan yeniden mesaj isteyen akış tasarla.
  • Medya önce FTS'e: fotoğraf/video/ses/belge URL'i FTS'ten gelmeli; harici URL kabul edilmez.
  • Belge adresleri değişti: güncel yol bip.com/tr/gelistiriciler/… (İngilizcesi bip.com/en/developers/…); eski /tr/category/dokumanlar/… ve /eng/category/developer/… 404.
  • Örnek kod eski: Turkcell/BiP.AI (Java/Spring, 20 commit) yol gösterir; aktif bakım izi yok. 2021 tarihli bir issue'da eski başvuru adresine e-posta gitmediği yazıyor — güncel adres partnering@.
  • Sorulacaklar: şahıs şirketi kabul ediliyor mu · aylık ücret ve kurulum bedeli · kota değerleri · oturum süresi ve mesaj sayısı · kullanıcı yazmadan bildirim yolu · MSISDN şartı ve KVKK'da veri sorumlusu/işleyen rolleri · geri besleme isteklerinde imza, IP listesi, retry · PRP test hesabı · güncel type kodları · tek hesapla çok servis · ödeme komisyonu · API sürümleme/kullanımdan kaldırma planı.
