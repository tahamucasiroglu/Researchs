§ 5Güncelleme almak: getUpdates mi, webhook mu?

getUpdates (uzun yoklama)Webhook
KullanımGET …/getUpdates?offset={SON_ID+1}&timeout=30POST …/setWebhook (url + secret_token)
Nasıl çalışırBot sorar; Telegram yeni güncelleme gelene ya da timeout dolana kadar bekletirTelegram her güncellemeyi adresine POST eder
SunucuYalnız dışarı çıkış; NAT/ev ağı arkasında çalışırİnternetten erişilen HTTPS, port 443/80/88/8443
SertifikaGerekmezGeçerli sertifika ya da yüklenen öz-imzalı sertifika
GüvenlikToken yeterGelen istekte X-Telegram-Bot-Api-Secret-Token başlığı = senin secret_token'ın olmalı
ÖlçekTek süreç1–100 eşzamanlı bağlantı (vars. 40); yatay ölçeklenir
BirlikteWebhook tanımlıyken getUpdates çalışmaz → önce deleteWebhook
  • Onaylama: işlediğin en büyük update_id + 1'i offset olarak gönder → öncekiler silinir.
  • Saklama: alınmayan güncelleme en çok 24 saat tutulur; bot bir günden uzun kapalıysa kayıp.
  • timeout: 0 = kısa yoklama, yalnız deneme için. Üretimde 25–50 sn yaygın TAHMİN.
  • allowed_updates: boş liste → chat_member, message_reaction, message_reaction_count dışındaki her şey; hiç verilmezse önceki ayar kalır.
  • Webhook cevabı: hızlı 200 dön, işi kuyruğa at; aynı update_id tekrar gelebilir → tekilleştir TAHMİN (genel pratik).

§ 7Derin bağlantı ve numara doğrulama

URL / kullanımNe yapar
https://t.me/{BOT_USERNAME}?start={PAYLOAD}Kullanıcı Başlat'a basar → bot /start {PAYLOAD} alır. Web'deki hesabı Telegram kullanıcısıyla eşlemenin standart yolu

PAYLOAD kuralıA-Z a-z 0-9 _ -, en çok 64 karakter. Daha uzun / ikili veri → base64url ya da sunucuda tut, kısa anahtar gönder

Güvenli eşleme

PAYLOAD'a kullanıcı no / e-posta gibi tahmin edilebilir değer koyma. Tek kullanımlık, süreli (ör. 10 dk), rastgele kod üret; bot alınca eşle, kodu sil, web tarafında "bağlandı" onayı göster. Bağlantı başkasına iletilirse yanlış kişi bağlanabilir.

Numara paylaşımı (request_contact)
AdımNe yap
1. Düğmeyi göster§ 6'daki reply keyboard JSON'u. Bot numarayı kendiliğinden göremez
2. Gelen kartı denetlemessage.contact.user_id == message.from.id olmalı. Ataç menüsünden başkasının kartı da gelebilir; eşleşmiyorsa reddet
3. Normalize etBaşında + olmayabilir → E.164'e çevir (ör. +90 5XX XXX XX XX → +905XXXXXXXXX)

Eşleşme geçtiyse numara, Telegram'ın kayıtta doğruladığı numaradır; ama SMS doğrulamasının yasal karşılığı değildir (finans/kimlik işlerinde ayrıca değerlendir). Numarasız (anonim numaralı) hesaplar da olabilir.

§ 8C# örnekleri (.NET, HttpClient + System.Text.Json)

Gizli değerler ortam değişkeninden: TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET. Kütüphane gerekmez; hazır istemci isteyen Telegram.Bot NuGet paketine bakabilir.

Mesaj gönder (inline klavyeli) + 429 yönetimi

// Konsol uygulaması, .NET 8+ (ImplicitUsings açık)
using System.Net.Http.Json;
using System.Text.Json.Nodes;

var token = Environment.GetEnvironmentVariable("TELEGRAM_BOT_TOKEN")
            ?? throw new InvalidOperationException("TELEGRAM_BOT_TOKEN yok");
var http = new HttpClient
{
    BaseAddress = new Uri($"https://api.telegram.org/bot{token}/"),
    Timeout = TimeSpan.FromSeconds(60)                // getUpdates timeout(30) + pay; ilk istekten önce ayarlanmalı
};

async Task<JsonNode?> CallAsync(string method, object body, CancellationToken ct = default)
{
    while (true)
    {
        using var res = await http.PostAsJsonAsync(method, body, ct);
        var json = JsonNode.Parse(await res.Content.ReadAsStringAsync(ct))!;
        if (json["ok"]!.GetValue<bool>()) return json["result"];

        var code = json["error_code"]?.GetValue<int>();
        if (code == 429)                               // hız sınırı
        {
            var wait = json["parameters"]?["retry_after"]?.GetValue<int>() ?? 1;
            await Task.Delay(TimeSpan.FromSeconds(wait), ct);
            continue;
        }
        // 403: kullanıcı başlatmamış / engellemiş → kaydı pasif yap, tekrar deneme
        throw new HttpRequestException($"{method}: {code} {json["description"]}");
    }
}

await CallAsync("sendMessage", new
{
    chat_id = 123456789,                               // {CHAT_ID} — /start ile öğrenilir
    text = "Siparişiniz hazır. Teslim almak için saat seçin:",
    reply_markup = new
    {
        inline_keyboard = new[]
        {
            new object[] { new { text = "Bugün 14:00", callback_data = "slot:today:14" },
                           new { text = "Yarın 10:00", callback_data = "slot:tmrw:10" } }
        }
    }
});

Uzun yoklama döngüsü (getUpdates + offset + timeout)

// Önceki parçanın devamı (aynı Program.cs: http + CallAsync)
long offset = 0;
using var cts = new CancellationTokenSource();
Console.CancelKeyPress += (_, e) => { e.Cancel = true; cts.Cancel(); };

while (!cts.IsCancellationRequested)
{
    JsonNode? updates;
    try
    {
        updates = await CallAsync("getUpdates", new
        {
            offset,
            timeout = 30,                              // uzun yoklama
            allowed_updates = new[] { "message", "callback_query" }
        }, cts.Token);
    }
    catch (OperationCanceledException) when (cts.IsCancellationRequested) { break; }
    catch (Exception e) when (e is HttpRequestException or TaskCanceledException)
    { await Task.Delay(5000); continue; }             // ağ hatası / HttpClient zaman aşımı: bekle, sürdür

    foreach (var u in updates!.AsArray())
    {
        offset = u!["update_id"]!.GetValue<long>() + 1;   // onayla
        await HandleUpdateAsync(u);
    }
}

async Task HandleUpdateAsync(JsonNode u)
{
    if (u["message"]?["text"]?.GetValue<string>() is string text && text.StartsWith("/start"))
    {
        var chatId  = u["message"]!["chat"]!["id"]!.GetValue<long>();
        var payload = text.Length > 7 ? text[7..] : null;   // derin bağlantı kodu
        // payload → sunucuda tek kullanımlık kodla eşle, chatId'yi sakla
        await CallAsync("sendMessage", new { chat_id = chatId, text = "Bağlantı kuruldu." });
    }
    else if (u["callback_query"] is JsonNode cq)
    {
        var data = cq["data"]?.GetValue<string>();
        await CallAsync("answerCallbackQuery", new
        {
            callback_query_id = cq["id"]!.GetValue<string>(),
            text = data == "slot:today:14" ? "Bugün 14:00 seçildi" : "Seçildi"
        });
    }
}

Webhook ucu + secret_token denetimi (ASP.NET Core minimal API)

// Ayrı proje: Microsoft.NET.Sdk.Web, .NET 9+ (JsonNode.ParseAsync)
using System.Security.Cryptography;
using System.Text;
using System.Text.Json.Nodes;

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();
var secret = Environment.GetEnvironmentVariable("TELEGRAM_WEBHOOK_SECRET")
             ?? throw new InvalidOperationException("TELEGRAM_WEBHOOK_SECRET yok");

app.MapPost("/telegram/webhook", async (HttpRequest req) =>
{
    var got = req.Headers["X-Telegram-Bot-Api-Secret-Token"].ToString();
    if (!CryptographicOperations.FixedTimeEquals(            // sabit zamanlı karşılaştırma
            Encoding.UTF8.GetBytes(got), Encoding.UTF8.GetBytes(secret)))
        return Results.Unauthorized();

    var update = await JsonNode.ParseAsync(req.Body);
    // update_id ile tekilleştir, kuyruğa at, hemen 200 dön
    _ = update?["update_id"]?.GetValue<long>();
    return Results.Ok();
});

app.Run();
