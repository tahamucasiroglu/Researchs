# Ayrıştırılacaklar (gelen kutusu)

Hafta boyunca yaptığım çalışmaları buraya kendi adlandırdığım klasörlerle atıyorum. Claude'a "ayrıştır" dediğimde her şey doğru kategoriye taşınır, README'ler ve [çalışma günlüğü](../CALISMA-GUNLUGU.md) güncellenir, buradan silinir.

Kurallar: [.claude/rules/ayristirma.md](../.claude/rules/ayristirma.md)

**Her klasöre bir `README.md` (veya not) koy:** ne yaptım, hangi kaynaktan (ör. BTK Akademi kursu, video bağlantısı), varsa tarih. Kod incelenmez, anlatılan esas alınır.

> Bu klasörün içeriği git'e gönderilmez (`.gitignore`), yalnızca bu README depoda durur.
