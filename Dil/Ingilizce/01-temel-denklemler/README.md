# Temel Denklemler (İngilizce)

İngilizce cümlenin iskeletini kurar. Ana denklem `Subject + Verb + Object` (SVO) biçimindedir ve kelime sırası anlamı belirler; Türkçedeki gibi ek eklenerek değil, ayrı kelimelerle (yardımcı fiil, edat) anlam kurulur. Özne zorunludur: Türkçede "Geliyorum" yeterliyken İngilizcede "I am coming" denir; anlamca öznesiz cümlelerde "it" veya "there" kullanılır.

Fiilin beş hâli (V1 yalın, V2 geçmiş, V3 past participle, V4 -ing, V5 -s) ve be/do/have yardımcı fiilleri tüm zamanların yapı taşıdır. Sayfa olumlu, olumsuz ve soru cümlesini aynı algoritmayla kurmayı öğretir.

## Sayfadaki başlıklar

1. Ana denklem: SUBJECT + VERB + OBJECT
2. Zorunlu özne: İngilizce cümle öznesiz olmaz
3. İngilizce'de ek yoktur, kelime vardır
4. Fiilin beş hâli: V1, V2, V3, V4, V5
5. Yardımcı fiil kavramı: be, do, have
6. Temel cümle kurma algoritması
7. Olumlu / olumsuz / soru üçlüsü
8. Alıştırmalar
9. Özet
