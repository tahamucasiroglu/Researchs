Konu 25 · Cümle dönüşümleri

Conditionals — 0, 1, 2, 3, mixed ve unless

Koşul cümlesinin tipi gerçeklik derecesine göre seçilir: her zaman doğru (0), olası gelecek (1), hayalî şimdi (2), değiştirilemez geçmiş (3). Kural: hayal ne kadar uzaksa fiil o kadar geriye kayar.

İngilizce Defter Rehberi · B1–B2 · 29 Ekim 2026

Anlam: -se/-sa (1) · -se … -ardı (2) · -seydi … -ardı (3).

§ 2Ne zaman, nasıl kullanılır

  • 0 tip — kural, bilimsel ya da sistem davranışı. If the token expires, the API returns 401. — Jeton süresi dolarsa API 401 döner.
  • 1 tip — gerçekçi olasılık. If we finish early, I'll buy you lunch. — Erken bitirirsek sana öğle yemeği ısmarlarım.
  • 1 tipte will yerine modal / emir. If you see an error, call me. / …you can retry.
  • 2 tip — gerçek dışı ya da düşük olasılık. If I won the lottery, I'd quit. — Piyango çıksa bırakırdım.
  • 2 tip — tavsiye: If I were you… If I were you, I'd ask for a raise. — Yerinde olsam zam isterdim.
  • 3 tip — geçmiş pişmanlık, değiştirilemez. If we had tested it, we wouldn't have lost data. — Test etseydik veri kaybetmezdik.
  • unless = if … not. Unless you save it, you'll lose it. — Kaydetmezsen kaybedersin.
  • as long as / provided that = yeter ki. You can work remotely as long as you join the stand-up.
  • in case = ihtimale karşı (koşul değil, önlem). Back it up in case something goes wrong.
  • Resmî devrik koşul (if'siz): Should you need help, … · Were I you, … · Had I known, … (Konu 30).

§ 3İpucu kelimeler

  • if cümlesinde will / would yok (istisna: kibar rica If you would wait here…).
  • 2. tipte were bütün öznelerde doğru (resmî): If he were here…; konuşmada was de duyulur.
  • Cümlelerin sırası değişebilir; if başta ise virgül: If it rains, we'll stay. / We'll stay if it rains.
  • would kısaltması 'd; had kısaltması da 'd → If I'd known, I'd have come (birincisi had, ikincisi would).

§ 6Alıştırma

A. Doğru biçim

  1. If you ___ (mix) red and blue, you get purple.
  2. If the client ___ (agree), we ___ (start) on Monday.
  3. If I ___ (be) you, I ___ (not / sign) that contract.
  4. If we ___ (leave) earlier, we ___ (not / miss) the flight.
  5. If she ___ (study) CS, she ___ (be) a developer now. (mixed)
  6. ___ you hurry, you'll be late. (unless)

B. Çevir

  1. Zamanım olsa sana yardım ederdim.
  2. Haber verseydin seni havalimanından alırdım.
  3. Bir sorun olursa beni ara.

C. Hatayı bul

  1. If I will see her, I will tell her.
  2. If he would have studied, he would pass.
  3. I'd buy it if I have money.
Cevapları göster
  1. mix · 2. agrees / will start · 3. were / wouldn't sign · 4. had left / wouldn't have missed · 5. had studied / would be · 6. Unless
  2. If I had time, I would help you.
  3. If you had told me, I would have picked you up from the airport.
  4. If there is a problem, call me.
  5. If I see her, I will tell her.
  6. If he had studied, he would have passed.
  7. I'd buy it if I had money.
