used to, would, be used to, get used to

Dört yapı benziyor ama iki ayrı anlam taşır: used to / would = "eskiden yapardım"; be / get used to = "alışığım / alışıyorum". Ayırt edici işaret: to'dan sonra V1 mi V-ing mi geliyor.

İngilizce Defter Rehberi · B1–B2 · 29 Ekim 2026

§ 1Deftere yaz

Deftere yaz — Dört yapı

Formüller: used to + V1 (eskiden …rdı) · would + V1 (eskiden …rdı, yalnız eylem) · be used to + V-ing/isim (alışkın olmak) · get used to + V-ing/isim (alışmak)

used to (geçmiş alışkanlık)be used to (alışkın)
OlumluI used to work nights.I'm used to working nights.
OlumsuzI didn't use to work nights.I'm not used to working nights.
SoruDid you use to work nights?Are you used to working nights?

Anlam: used to = "eskiden gece çalışırdım (artık değil)" · be used to = "gece çalışmaya alışkınım".

§ 2Ne zaman, nasıl kullanılır

  • used to + V1 — eskiden olan, artık olmayan alışkanlık. I used to play games every night. — Eskiden her gece oyun oynardım.
  • used to + V1 — eskiden olan durum (stative de olur). There used to be a café here. — Burada eskiden bir kafe vardı.
  • would + V1 — geçmişte tekrarlanan eylem (hikâye anlatımında, durum için değil). Every summer we would go to the coast. — Her yaz sahile giderdik.
  • be used to + V-ing / isim — alışkın olmak. She's used to the noise. — Gürültüye alışkın.
  • get used to + V-ing / isim — alışmak (süreç). You'll get used to the new IDE. — Yeni IDE'ye alışırsın.
  • Present simple ile şimdiki alışkanlık (used to'nun şimdiki hâli yok). I usually work late. I use to work late.

§ 3İpucu kelimeler

  • used to → any more / no longer ile karşılaştırma: He used to smoke, but he doesn't any more.
  • be used to / get used to → to burada edattır, arkasından isim ya da V-ing gelir (look forward to, object to gibi).
  • would ile stative fiil kullanılmaz: I would have a dog → I used to have a dog.

§ 6Alıştırma

A. used to / would / be used to / get used to

  1. When I was a student, I ___ (stay) up all night.
  2. Don't worry, you'll soon ___ (work) with this team.
  3. She ___ (not / have) a laptop before this job.
  4. I ___ (speak) English at meetings now; it's not a problem.
  5. Every Sunday my grandfather ___ (take) us fishing.

B. Çevir

  1. Eskiden çay içmezdim.
  2. Erken kalkmaya alışkın değilim.
  3. Eskiden burada bir banka var mıydı?

C. Hatayı bul

  1. I'm not used to get up early.
  2. Did you used to live here?
  3. We would have a cat when I was young.
