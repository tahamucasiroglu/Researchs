so / such ve too / enough

so / such derecesini artırır ("o kadar"), too fazlalık yüzünden olmayanı, enough yeterliliği anlatır. Hepsi yerleşim kuralıyla öğrenilir: hangisi sıfattan önce, hangisi sonra?

İngilizce Defter Rehberi · A2–B1 · 29 Ekim 2026

§ 1Deftere yaz

Deftere yaz — Yerleşim kuralları

Formüller: so + sıfat/zarf · such + a/an + (sıfat) + tekil isim · such + (sıfat) + çoğul/sayılamaz · so … that + cümle · too + sıfat (+ for sb) + to V1 · sıfat + enough + to V1 · enough + isim

KalıpÖrnek
Olumlutoo + sıfat + to V1It's too slow to use.
Olumsuznot + sıfat + enough + to V1It isn't fast enough to use.
SoruIs it + sıfat + enough?Is it fast enough?
so/suchso … that / such … thatIt was so slow that we gave up. / It was such a slow build that we gave up.

Anlam: so/such = o kadar · too = fazla/çok (olumsuz sonuç) · enough = yeterince.

§ 2Ne zaman, nasıl kullanılır

  • so + sıfat. The docs are so clear. — Doküman o kadar net ki.
  • such + a + sıfat + isim. It's such a clean API. — O kadar temiz bir API ki.
  • such + çoğul / sayılamaz. such good people, such bad weather — öyle iyi insanlar, öyle kötü hava.
  • so many / so much / so few / so little. There were so many bugs. — O kadar çok hata vardı ki.
  • so / such … that = sonuç. I was so tired that I fell asleep at my desk. — O kadar yorgundum ki masamda uyuyakaldım.
  • too + sıfat = gerekenden fazla (sonuç olumsuz). This laptop is too heavy to carry. — Bu dizüstü taşınamayacak kadar ağır.
  • too + sıfat + for + kişi + to V1. The exam was too hard for me to pass.
  • too much / too many + isim. There are too many meetings. — Çok fazla toplantı var.
  • sıfat + enough = yeterli. Is the server powerful enough? — Sunucu yeterince güçlü mü?
  • enough + isim. We don't have enough time. — Yeterince zamanımız yok.

§ 3İpucu kelimeler

  • enough sıfat/zarftan sonra, isimden önce: old enough / enough money.
  • too = "fazla" (olumsuz), very = "çok" (nötr): It's very hot (ama içilebilir) / It's too hot to drink (içilemez).
  • so sıfatsız isimle olmaz: so a nice day → such a nice day.

§ 6Alıştırma

A. so / such / too / enough

  1. It was ___ a long meeting that I fell asleep.
  2. The font is ___ small to read.
  3. He isn't experienced ___ to lead the team.
  4. There's ___ much noise here; I can't think.
  5. We had ___ terrible weather last week.
  6. Do we have ___ licenses for everyone?

B. Çevir

  1. Bu kahve içilemeyecek kadar sıcak.
  2. O kadar iyi bir ekip ki burada kalmak istiyorum.
  3. Yeterince zamanımız var mı?

C. Hatayı bul

  1. The room isn't enough big for 20 people.
  2. She is so a talented designer.
  3. I have too many work today.
