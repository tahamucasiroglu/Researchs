Passive voice (edilgen) ve causative (have / get something done)

Passive, işi yapanı değil işten etkileneni öne çıkarır: The bug was fixed. — Hata düzeltildi. Formül tek: be + V3; zaman be'nin üstünde taşınır.

İngilizce Defter Rehberi · B1–B2 · 29 Ekim 2026

§ 1Deftere yaz

Deftere yaz — Passive denklemi

Formül: Nesne + be (zamana göre) + V3 (+ by + yapan)

KalıpÖrnek
OlumluO + be + V3The data is encrypted.
OlumsuzO + be + not + V3The data isn't encrypted.
SoruBe + O + V3?Is the data encrypted?

Causative: have / get + nesne + V3 → başkasına yaptırmak: I had my laptop repaired. — Dizüstümü tamir ettirdim.

Anlam: -il / -in (edilgen) · -dır / -tir (ettirgen).

§ 2Bütün zamanlarda passive

ZamanAktifPassive (be + V3)
Present simpleThey test the code.The code is tested.
Present continuousThey are testing the code.The code is being tested.
Past simpleThey tested the code.The code was tested.
Past continuousThey were testing the code.The code was being tested.
Present perfectThey have tested the code.The code has been tested.
Past perfectThey had tested the code.The code had been tested.
willThey will test the code.The code will be tested.
going toThey are going to test it.It is going to be tested.
Future perfectThey will have tested it.It will have been tested.
ModalThey must test it.It must be tested.
Perfect modalThey should have tested it.It should have been tested.
InfinitiveI want them to test it.I want it to be tested.
GerundI hate people watching me.I hate being watched.

(Perfect continuous zamanların passive'i pratikte kullanılmaz.)

§ 3Ne zaman, nasıl kullanılır

  • Yapan bilinmiyor / önemsiz. My bike was stolen. — Bisikletim çalındı.
  • Teknik metin, süreç anlatımı. The request is validated and then stored. — İstek doğrulanır ve sonra kaydedilir.
  • Suçlamayı yumuşatma. Mistakes were made. — Hatalar yapıldı.
  • by + yapan — yapan önemliyse. The library was written by a student. — Kütüphane bir öğrenci tarafından yazıldı.
  • İki nesneli fiiller (give, send, show, offer, tell): kişi özne olur. I was given access. — Bana erişim verildi.
  • get-passive (günlük, beklenmedik). He got fired. — Kovuldu. The file got deleted.
  • It is said / believed that… It is believed that… = He is believed to be… — …olduğuna inanılıyor.
  • Causative have = yaptırmak (hizmet). We had the servers upgraded. — Sunucuları yükselttirdik.
  • Causative get = yaptırmak (günlük, çaba). I need to get my hair cut. — Saçımı kestirmem gerek.
  • have + kişi + V1 / get + kişi + to V1 (aktif ettirgen). I'll have IT reset it. / I'll get IT to reset it. — BT'ye sıfırlatırım.

§ 4İpucu kelimeler

  • Passive işaretleri: by …, edilgen anlam "-ildi, -ınıyor", teknik dokümanda süreç fiilleri.
  • Nesnesiz (intransitive) fiiller passive olmaz: happen, arrive, die, sleep, occur, exist. It was happened.
  • Kişi passive'de "bana/ona" → I was told / she was asked / we were shown.

§ 7Alıştırma

A. Passive'e çevir

  1. Someone has changed the password.
  2. They are building a new data center.
  3. They will announce the results tomorrow.
  4. You must not share this link.
  5. Somebody told me about the outage.

B. Causative

  1. A technician is going to install the AC for us. → We ___
  2. Bir mekanik arabamı tamir etti. (have something done ile) →

C. Çevir

  1. Bu kütüphane 2015'te yazıldı.
  2. Sorun şu an inceleniyor.

D. Hatayı bul

  1. The meeting was took place online.
  2. A new feature has been add.
  3. The package will deliver tomorrow.
Cevapları göster
  1. The password has been changed. · 2. A new data center is being built. · 3. The results will be announced tomorrow. · 4. This link must not be shared. · 5. I was told about the outage.
  2. We are going to have the AC installed.
  3. I had my car repaired (by a mechanic).
  4. This library was written in 2015.
  5. The issue is being investigated right now.
  6. The meeting took place online. (take place passive olmaz)
  7. A new feature has been added.
  8. The package will be delivered tomorrow.
