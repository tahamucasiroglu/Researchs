Konu 01 · Temel

Cümle temeli ve kelime sırası

İngilizcede anlamı ekler değil kelime sırası taşır. Her cümlede özne ve çekimli bir fiil bulunur; anlamca öznesi olmayan cümlede bile yer tutucu bir özne (it, there) yazılır.

İngilizce Defter Rehberi · A1 · 29 Ekim 2026

§ 1Deftere yaz

Deftere yaz — Ana denklem

Formül: S + V + O + (yer) + (zaman) — Özne + Fiil + Nesne + Yer + Zaman

KalıpÖrnek
OlumluS + V + OI write code every day.
OlumsuzS + do/does not + V1 + OI don't write code every day.
SoruDo/Does + S + V1 + O?Do you write code every day?

Varlık: There is + tekil · There are + çoğul → "...var". Boş özne: It is + sıfat/zaman/hava → "...(dır)".

Anlam: Türkçe "Her gün kod yazarım" = İngilizcede sıra sabit: kim + ne yapar + neyi + nerede + ne zaman.

§ 2Ne zaman, nasıl kullanılır

  • Sıra anlamı belirler. Özne ile nesnenin yeri değişirse anlam değişir. The dog bit the man. — Köpek adamı ısırdı. / The man bit the dog. — Adam köpeği ısırdı.
  • Özne zorunludur. Türkçedeki gibi kişi eki yoktur; özne zamiri yazılır. I'm tired. — Yorgunum.
  • Zaman ve yer genelde sonda, sıra: yer → zaman. We met at the office yesterday. — Dün ofiste buluştuk.
  • There is / there are bir şeyin var olduğunu ilk kez söyler; fiil arkadaki isme göre çekilir. There are two bugs in this function. — Bu fonksiyonda iki hata var.
  • It hava, zaman, mesafe ve "durum" cümlelerinde boş öznedir. It's raining. — Yağmur yağıyor. It's 5 km to the station. — İstasyona 5 km var.
  • It + sıfat + to V1 / that…: asıl özneyi sona taşır. It is hard to learn English. — İngilizce öğrenmek zor.
  • Sıfat ismin önüne, edat ismin önüne gelir (Türkçede edat sonra gelir). in the new office — yeni ofiste.
  • Sıklık zarfı asıl fiilden önce, be'den sonra gelir. She usually works from home. / She is usually at home.

§ 3İpucu kelimeler

  • Var/yok: there is / there are / there was / there will be
  • Boş özne: it's + hava (cold, sunny), it's + saat/gün (5 o'clock, Monday), it takes + süre + to V1
  • Sıklık zarfları (fiil önü): always, usually, often, sometimes, rarely, never

§ 6Alıştırma

A. Boşluk doldur (there is / there are / it is)

  1. ___ two new messages in the channel.
  2. ___ too hot in this room.
  3. ___ a problem with the server.
  4. ___ easy to break production on a Friday.

B. Çevir (TR → EN)

  1. Bugün çok soğuk.
  2. Bu projede çok fazla dosya var.
  3. Her sabah e-postalarımı kontrol ederim.

C. Hatayı bul

  1. Is important to write tests.
  2. There is three tickets in the backlog.
  3. I very like this framework.
Cevapları göster
  1. There are · 2. It is · 3. There is · 4. It is
  2. It is very cold today.
  3. There are too many files in this project.
  4. I check my emails every morning.
  5. It is important to write tests.
  6. There are three tickets in the backlog.
  7. I like this framework very much. (very fiili nitelemez; ya da I really like…)
