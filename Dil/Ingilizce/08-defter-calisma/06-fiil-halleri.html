Fiilin hâlleri — V1, V2, V3, -ing, -s ve en sık 60 düzensiz fiil

Bütün zamanlar fiilin beş hâlinden kurulur: V1 (yalın), V2 (geçmiş), V3 (past participle), V-ing ve V1+s. Düzenli fiilde V2 = V3 = -ed; düzensiz fiillerin ezberi bu sayfadaki tablodur.

İngilizce Defter Rehberi · A1–A2 · 29 Ekim 2026

§ 1Deftere yaz

Deftere yaz — Beş hâl ve nerede kullanılır

HâlÖrnek (work / write)Kullanıldığı yer
V1work / writepresent simple, modal sonrası, do/does/did sonrası, emir, to + V1
V1+sworks / writespresent simple, he/she/it
V2worked / wrotepast simple (yalnız olumlu)
V3worked / writtenperfect (have + V3), passive (be + V3)
V-ingworking / writingcontinuous (be + V-ing), gerund
KalıpÖrnek
OlumluS + V2She wrote the spec.
OlumsuzS + didn't + V1She didn't write the spec.
SoruDid + S + V1?Did she write the spec?

Anlam: V2 yalnız olumlu geçmişte görünür; yardımcı fiil gelince ana fiil V1'e (did) ya da V3'e (have/be) döner.

§ 2Yazım kuralları

EkKuralÖrnek
-sçoğu fiil + sworks, runs
-es-s, -sh, -ch, -x, -o ile bitenfixes, pushes, watches, goes, does
-iesünsüz + ytry → tries, copy → copies (ama play → plays)
-edçoğu fiil + edworked, deployed
-d-e ile bitenuse → used, save → saved
-iedünsüz + ytry → tried, apply → applied
çift ünsüztek heceli, ünsüz-ünlü-ünsüzstop → stopped, plan → planned (BrE: cancelled, AmE: canceled)
-ing-e düşerwrite → writing, make → making (ama be → being, see → seeing)
-ying-ie → ylie → lying, die → dying
çift ünsüz -ingyukarıdakiyle aynırun → running, commit → committing

-ed okunuşu: /t/ (p, k, s, sh, ch, f sonrası: worked), /d/ (diğerleri: played), /ɪd/ (t, d sonrası: started, needed).

§ 4İpucu kelimeler

  • did / didn't / does / do / can / will / to → arkası V1
  • have / has / had / be (passive) → arkası V3
  • am / is / are / was / were (continuous) → arkası V-ing

§ 7Alıştırma

A. Doğru hâli yaz

  1. Have you ___ (see) the logs?
  2. She ___ (write) the README yesterday.
  3. The build was ___ (break) by my commit.
  4. He usually ___ (fix) bugs on Mondays.
  5. We are ___ (plan) the release.

B. Çevir

  1. Şifreyi unuttum. (past simple)
  2. Bu kodu kim yazdı?
  3. Toplantı bitti. (present perfect)
